# Privacy Policy

Last updated: November 10, 2026

## 1. Overview

Fedora Google Drive Integration is a personal,
non-commercial application used to access Google Drive
through rclone on a Fedora Linux computer.

The application is intended exclusively for personal use.

## 2. Information Accessed

The application requests permission to access Google Drive
files and associated metadata.

This access enables the user to browse, download, upload,
modify, organize, and delete files through rclone.

## 3. Data Usage

Google Drive data is accessed solely to perform file
operations requested by the account owner.

The application does not use Google Drive data for
advertising, analytics, profiling, or marketing.

## 4. Data Storage and Sharing

OAuth authentication credentials are stored locally
on the user's computer by rclone.

File contents may be temporarily cached locally as
necessary for file operations.

The application does not operate an independent server
for collecting or storing Google Drive data.

Google Drive data is not sold or shared with third parties
for advertising or commercial purposes.

## 5. Data Security

Access to Google Drive is authorized through Google's
OAuth 2.0 authentication system.

The user can revoke the application's access at any time
through their Google Account security settings.

## 6. Data Retention and Deletion

The application does not maintain an independent database
of Google Drive information.

Locally cached data and authentication credentials can
be removed by the user.

Revoking access prevents further authorized access to
Google Drive through the application.

## 7. Changes to This Policy

This privacy policy may be updated to reflect changes
in the application's functionality or data handling.
