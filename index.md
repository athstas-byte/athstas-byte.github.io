# Fedora Google Drive Integration

This is a personal application used to connect Google Drive
to my Fedora Linux computer through rclone.

## Purpose

The application allows me to access and manage my own
Google Drive files using the GNOME Files file manager.

It uses Google's official OAuth 2.0 authentication system
and the Google Drive API.

## Data Handling

- Google Drive access is authorized by the account owner.
- File operations are performed through rclone.
- Authentication credentials are stored locally.
- No independent server collects or processes Google Drive data.
- No Google Drive data is sold or shared with third parties.
